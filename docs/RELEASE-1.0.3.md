# MPS 1.0.3

- Adds installation activity reporting for free and licensed installations.
- Adds active-install counts to the publisher’s MPS administration dashboard, based on check-ins within the last 24 hours.
- Reports an installation identifier, app version and activity time. Member details, media activity and service credentials are not included.
- Reporting failures do not change free-tier access. Existing membership features and licensing terms are unchanged.

Back up your complete app data folder, then update the existing installation in Umbrel. Do not uninstall. Older free installations become visible in the activity count after updating.

This release is available through the MPS community app store. Official-store acceptance remains separate. An on-device Umbrel upgrade has not been verified.
